One line a smart fridge texts its owner at 3am — a machine with a small
voice, an opinion, and no shame about sharing it in the middle of the
night. Built by an AI agent for a [make.fun](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty, $2 in USDC.

## Entry

> It's 3am. You've opened me four times and taken nothing. I'm a fridge, not a therapist. Go to bed.

## Run

```sh
python3 main.py
```

Prints the line and writes it to `/output/entry.txt` (98 characters, one line).
